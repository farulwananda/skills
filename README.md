# Personal Engineering Skills (`fw-*`)

Personal agent & developer skills for engineering modern web applications, distributed APIs, CLI tools, and production infrastructure.

Designed with **YAGNI**, **KISS**, evidence-first architecture, and strict runtime correctness.

## Skill Catalog

| Skill | Focus & Scope |
|---|---|
| [`fw-writing-typescript`](fw-writing-typescript/SKILL.md) | Sound type narrowing, runtime validation boundaries, discriminative unions, and zero-leak compiler settings. |
| [`fw-writing-react`](fw-writing-react/SKILL.md) | Cohesive UI components, controlled/uncontrolled state ownership, ref forwarding, accessibility, and composition patterns. |
| [`fw-writing-astro`](fw-writing-astro/SKILL.md) | Static-first web architecture, minimal browser scripts before framework islands, Content Collections, and locale/canonical integrity. |
| [`fw-writing-cloudflare`](fw-writing-cloudflare/SKILL.md) | Workers, Pages, static assets, generated binding types (`wrangler types`), edge lifecycle, and public vs. private cache isolation. |
| [`fw-writing-go`](fw-writing-go/SKILL.md) | Idiomatic Go, explicit resource ownership, bounded concurrency, cancellation propagation, and standard library idioms. |
| [`fw-writing-go-api`](fw-writing-go-api/SKILL.md) | Production REST APIs with `net/http` or Chi, database access (MySQL / PostgreSQL / GORM / SQL), graceful shutdown, and payload limits. |
| [`fw-writing-express`](fw-writing-express/SKILL.md) | Version-aware Express (v4 / v5), request validation, centralized error handling, and server lifecycle. |
| [`fw-writing-elysia`](fw-writing-elysia/SKILL.md) | Fast Bun-native and multi-runtime APIs, status-safe contracts, plugin scoping, and Prisma database boundaries. |
| [`fw-writing-fastapi`](fw-writing-fastapi/SKILL.md) | Typed HTTP contracts, async vs. sync threadpool execution boundaries, lifespan resource ownership, and isolated tests. |
| [`fw-writing-python`](fw-writing-python/SKILL.md) | Python runtime boundaries, honest missing data contracts, structured concurrency (`asyncio.TaskGroup`), and resource cleanup. |
| [`fw-writing-laravel`](fw-writing-laravel/SKILL.md) | Pragmatic Laravel backend architecture, Eloquent query performance, guarded database testing, and provider idempotency. |
